- ☎️ โทร 02-000-0000

เป็นเว็บแบบธรรมดา (HTML + CSS) ไม่ต้องติดตั้งโปรแกรมเพิ่ม ไม่ต้อง build

## ดูเว็บจริงได้ที่ไหน

👉 **https://baan-mae-bakery.vercel.app**

เว็บนี้อยู่บน Vercel ซึ่งเชื่อมกับ GitHub ไว้ เมื่อ push งานขึ้น GitHub แล้ว ปกติเว็บจะอัปเดตเองภายในไม่กี่นาที

ถ้าอยากดูบนเครื่องตัวเองก่อน ให้ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย

## ในโปรเจกต์มีไฟล์อะไร

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บหลัก มีชื่อร้าน เวลาเปิด-ปิด เมนูและราคา และช่องทางติดต่อ |
| `style.css` | หน้าตาของเว็บ เช่น สี ฟอนต์ ระยะห่าง กรอบการ์ด |
| `README.md` | ไฟล์อธิบายโปรเจกต์ (ไฟล์นี้) |
| `CLAUDE.md` | กฎการทำงานของโปรเจกต์ สำหรับ Claude Code |
| `.gitignore` | รายชื่อไฟล์ที่ไม่ให้ขึ้น GitHub เช่น `.env`, `*.pem` (ไฟล์ลับ) |

## วิธีแก้เมนูและราคา

เมนูทั้งหมดอยู่ในไฟล์ `index.html` ในส่วน `<ul>` หน้าตาแบบนี้:

```html
<ul>
  <li>ขนมชั้น — 45 บาท</li>
  <li>ทองหยิบ — 65 บาท</li>
  <li>ลูกชุบ — 50 บาท</li>
  <li>ฝอยทอง — 70 บาท</li>
  <li>ข้าวเหนียวมะม่วง — 80 บาท</li>
  <li>บัวลอย — 45 บาท</li>
</ul>
```

- **เปลี่ยนราคา** — แก้ตัวเลขในบรรทัดนั้น เช่น `<li>ขนมชั้น — 50 บาท</li>`
- **เพิ่มเมนูใหม่** — เพิ่มบรรทัดใหม่ใน `<ul>` เช่น `<li>สังขยาฟักทอง — 60 บาท</li>`
- **ลบเมนู** — ลบทั้งบรรทัด `<li>...</li>` ของเมนูนั้น

ข้อควรระวัง: ทุกเมนูต้องอยู่ระหว่าง `<li>` กับ `</li>` และอยู่ข้างใน `<ul>` ... `</ul>` เท่านั้น

แก้เสร็จแล้ว เปิด `index.html` ในเบราว์เซอร์เพื่อดูว่าถูกต้อง แล้วส่งงานขึ้น GitHub ตามหัวข้อถัดไป

## วิธีส่งงานขึ้น GitHub

ทำตามลำดับนี้ทุกครั้ง (แก้ทีละเรื่องเล็ก ๆ แก้เสร็จหนึ่งเรื่องก็ส่งเลย)

```bash
# 1. ดึงงานล่าสุดจาก GitHub ก่อน กันงานชนกัน
git pull

# 2. ดูว่าแก้ไฟล์อะไรไปบ้าง
git status

# 3. เลือกไฟล์ที่จะส่ง
git add index.html

# 4. เช็กอีกรอบว่าไม่มีไฟล์ลับหรือรหัสผ่านหลุดเข้าไป
git diff --staged

# 5. บันทึกงาน พร้อมเขียนให้ชัดว่าแก้อะไร (เป็นภาษาไทย)
git commit -m "ปรับราคาขนมชั้นเป็น 50 บาท"

# 6. ส่งขึ้น GitHub
git push
```

ข้อห้าม:

- ❌ ห้ามส่งไฟล์ลับ เช่น `.env`, `.env.local`, `*.pem`, รหัสผ่าน, API key, token
- ❌ ห้ามใช้ `git push --force` (รวมถึง `-f` และ `--force-with-lease`)
- ❌ ห้ามใช้ `git reset --hard`
- ✅ ถ้าต้องย้อนการแก้ ให้ใช้ `git revert <รหัส commit>` แทน
